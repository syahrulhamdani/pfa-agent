pfa: Technical Spec

One async Python process (API, Telegram polling, scheduler, LangGraph graphs), one Postgres database, one React web app.

How the Pieces Fit

Green: your codeBlue: LLM orchestrationGray: outside the process
Async everywhere it can be: async FastAPI endpoints, async SQLAlchemy with asyncpg, async python-telegram-bot, async LangGraph calls, APScheduler's asyncio scheduler, blocking file parsing pushed to a thread, and async fetches on the frontend.

Follow One Receipt

The PRD's core journey, traced through the pieces. Step through it.

Components

Extraction graph
Nodes: detect type, parse, extract (Gemini Pro), infer card, validate required fields, ask for missing input or await confirmation (interrupt), commit. Statement summary (count, highest, lowest, total) is computed in code.
prd.md > Upload and extraction, prd.md > Confirmation and data fields
Chat graph and recommendation graph
Flash Lite routes a message to casual reply, insights lookup, or recommendations. Numbers always come from the analytics service.
prd.md > Weekly summary and recommendations
Nudge scheduler
Fewer than 20 confirmed transactions: six default slots. Otherwise six clusters of past upload times. Ignored nudges get no follow-up.
prd.md > Adaptive nudges
REST API and web app
Async routers; React pages Today (landing), Dashboard, Budgets, Goals, Settings (banks and cards).
prd.md > Screens and Layout

Data Model

TableHolds
banks, cardsSet up in the web app. A card belongs to a bank.
categoriesSeeded list.
uploadsEach file you send and its status.
transactionsFields from the PRD plus status pending or confirmed. Only confirmed rows count.
budget_versionsCategory, month, amount, version. Highest version is current.
goalsName, target amount, target date, saved amount (assumption).
nudge_slots, weekly_summariesSlot times (default or learned); saved weekly stats and recommendations.

Run It

docker compose up -d db
uv run --env-file .env.example alembic upgrade head
uv run --env-file .env.example uvicorn pfa.main:app --reload
cd web && npm install && npm run dev      # then open http://localhost:5173

For the demo, use /demo_summary and /demo_nudge in Telegram.

Failure Modes and Simplifications

What can break
  • Blurry or failed extraction: unreadable fields go back to you; a total failure marks the upload failed and asks you to resend.
  • Gemini rate limit: one retry, then a short message.
  • App stops: nudges stop; paused confirmations resume from Postgres.
What was simplified
  • No login (single user via chat id), polling instead of webhooks, refetch instead of websockets, in-process scheduler, manual saved amount on goals, local-only run.
